# StainCore resource-pack mirror

`stain-tablist-pack.zip` is the client-facing resource pack for the Stain Games
Royale server (StainCore plugin). It lives in this public repo so the Minecraft
client can download it with a plain unauthenticated GET:

https://raw.githubusercontent.com/saxkeymc/Wasteland/main/staincore-pack/stain-tablist-pack.zip

The pack's development home is the private CobraLobby repo; every release the
built zip is copied here. Nothing else in this repo is related.
